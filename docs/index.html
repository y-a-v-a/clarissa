Six ciphers, taken apart

From Caesar's shift to the ADFGX cipher of 1918: try them below, then watch how each one works.

Playground

Runs the library's own code in your browser. Nothing is sent anywhere.

Caesar

Every letter moves the same number of places along the alphabet, wrapping from Z back to A. With only 25 possible keys, you can break it by trying them all.

Atbash

The alphabet folded in half: A swaps with Z, B with Y. There is no key, and encrypting twice gives you back what you started with.

Vigenère

A different Caesar shift for every letter, set by a repeating keyword. For three centuries it was called le chiffre indéchiffrable, until Babbage and Kasiski found the key's period.

Playfair

Letters are encrypted in pairs on a 5 × 5 square built from the key, which hides single-letter frequencies. It saw field use from the Boer War through World War II.

Scytale

A Spartan transposition: the letters stay the same, only their order changes. The rod is the key, so a rod of the same size is all you need to read it.

ADFGX

Used by the German army in 1918: every letter is split into two coordinates, then the coordinates are shuffled by column. Georges Painvin broke it that same year.

None of these ciphers is secure today: please don't use them for anything sensitive.
